Arch user repository [prince]

Personal pacman repository (git/AUR-style builds of the Cinnamon stack and friends), served via GitHub Pages.

Usage

Add the following to /etc/pacman.conf:

[prince]
SigLevel = Never
Server = https://princepaul.github.io/arch-repo/

Then run pacman -Syu and install packages as usual.
